# Kariso Estética 🧖‍♀️💅 - Proyecto Final

Sitio web profesional desarrollado para el curso de Desarrollo Web en Coderhouse. Enfocado en una experiencia de usuario elegante, minimalista y totalmente optimizada.

## 🚀 Demo
Puedes ver el sitio en vivo aquí: https://FacuFa1503.github.io/Kariso-Estetica-Proyecto-Final/

## ✨ Características (Criterios de Evaluación)
* **Diseño Responsivo:** Implementación de Grids y Flexbox (Bootstrap 5) sin errores de overflow-x.
* **Arquitectura SASS:** Código modular con uso de `@use`, variables y mixins para optimizar el reciclado de estilos.
* **Animaciones & Dinamismo:** Uso de la librería **AOS (Animate On Scroll)** para transiciones fluidas al navegar.
* **Optimización SEO:** Implementación de metadatos (Open Graph), jerarquía de títulos (H1-H5), atributos ALT en imágenes y performance con formato WebP.

## 🛠️ Tecnologías utilizadas
* HTML5 / CSS3
* Bootstrap 5 (Framework)
* SASS (Preprocesador)
* AOS Library (Animaciones)
* Google Fonts (Playfair Display & Poppins)

## 📂 Estructura del Proyecto
* `/index.html`: Página principal (Raíz).
* `/pages`: Secciones internas (Contacto, Nosotros, Galería, Servicios).
* `/scss`: Arquitectura modular de estilos.
* `/css`: Estilos compilados para producción.
* `/img`: Recursos visuales optimizados y favicon personalizado.
